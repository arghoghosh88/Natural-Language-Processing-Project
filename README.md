# 🧠 Bengali Natural Language Processing — Toxicity Detection

A Bengali Natural Language Processing (NLP) project focused on **toxicity detection and multi-label text classification**.

This project explores different NLP models and approaches for identifying toxic content in Bengali text and predicting multiple toxicity-related categories.

## 🎯 Project Objective

The main objective is to build and evaluate NLP models that can understand Bengali text and classify toxic content.

### Tasks

* **Subtask A:** Binary classification — Toxic / Non-Toxic
* **Subtask B:** Multi-label classification across multiple toxicity attributes
